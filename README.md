# PasteTrail · 贴迹

**留住每次复制，随时找回。**

PasteTrail = Paste（粘贴）+ Trail（轨迹）。这是一款面向 macOS 的本地剪贴板历史与素材保存工具，把复制过的文字、链接、图片和录屏集中呈现为可搜索、可编辑、可再次使用的卡片。

[English](README.en.md)

## 项目背景与痛点

在查资料、写文档、编程或与 AI 对话时，复制粘贴是贯穿整个工作流程的基础操作。系统剪贴板通常只保留最近一次复制的内容，长期保存和再次查找需要额外的整理步骤：

- **复制内容容易被覆盖**：刚复制的提示词、链接或文本，在下一次复制后就难以找回。
- **常用资料分散**：话术、代码片段和参考图片散落在聊天记录、笔记与文件夹中，重复使用时需要来回查找。
- **临时采集难以沉淀**：复制时没有顺手保存，之后又要回到原网页或对话重新寻找。
- **截图处理流程割裂**：截图、标注、提取文字和再次粘贴往往需要在多个工具之间切换。

PasteTrail 希望让“复制”自然成为资料采集的入口，让有用内容从临时剪贴板进入可回溯、可保留、可复用的个人素材库。

## 创作缘起与设计取向

### 给反复复制的日常，留一点记忆

在写文档、查资料、编程和与 AI 对话时，我们每天都会复制很多文本、截很多图。有时一个小时前才用过的内容，再次需要时仍要回到原来的页面重新寻找。常用资料有的留在备忘录，有的放进 Obsidian，还有一些只在剪贴板里短暂停留，随后就被覆盖。

PasteTrail 从这些细碎的重复出发：让复制过的内容自然留下来，集中在一个地方，等待回顾、编辑和再次使用。保存资料可以顺着原本的工作习惯发生，少一些额外整理的负担。

### 让截图、识字与录屏顺手衔接

截图时，颜色还原、文字识别和录屏都是很实际的需求。如果这些能力分散在不同工具中，每次操作前都要先决定用哪个应用、按哪个快捷键，处理完还得另找地方保存。

PasteTrail 将这些能力放进同一条工作流程：截图后直接标注或识别文字，需要展示操作过程时使用录屏，处理后的内容进入同一份历史。采集、加工和再次调用可以顺手衔接，减少来回切换。

### 好用，也要看着舒服

字体、文本框、图形样式和颜色，都会影响一个工具被日常使用时的感受。PasteTrail 重视这些细节，希望每一次查看和整理内容，都能带来一点「情绪价值」。

项目以纸感卡片承载零散资料，搭配受 Excalidraw 启发的手绘标注与低饱和配色。文字需要清楚易读，标注需要自然协调，界面也应为内容留出足够的空间。

截图既是临时记录，也可能成为要分享给同事、放进文档或留作参考的材料。让它容易处理、方便保存，也值得被认真呈现，是 PasteTrail 希望坚持的设计取向。

## 旨在解决的问题

| 问题 | 产品处理方式 | 预期价值 |
| --- | --- | --- |
| 上一次复制的内容被覆盖 | 自动记录剪贴板历史，保留时间与来源应用信息 | 减少重复查找和复制 |
| 重要内容被埋在大量记录里 | 关键词搜索、自定义标题和固定保存（Pin） | 更快定位常用资料 |
| 临时内容与长期资料混杂 | 为普通记录设置保留期，固定条目不参与自动清理 | 兼顾日常清理与长期积累 |
| 截图中的信息难以再利用 | 图片标注、本地 OCR、识别结果参与搜索 | 将截图转化为可查找的资料 |
| 内容找回后仍需重复操作 | 单击复制、双击粘贴，支持文本和图片二次编辑 | 缩短从查找到再次使用的路径 |

以上是产品目标，尚未通过用户研究或量化实验验证提效幅度。

## 当前功能

### 剪贴板历史与保存

- 记录文字、链接、图片、文件引用和录屏内容，以卡片形式集中浏览。
- 保留复制时间与来源应用信息，帮助回溯内容出处。
- 搜索文本正文、标题、来源应用名称和已识别的图片文字。
- 为重要内容添加标题、固定保存，并设置未固定记录的自动清理时间。
- 对相同类型、相同内容的重复复制进行去重，将已有记录移到前面。
- 编辑历史文本、标注图片，将内容重新用于当前工作。
- 将卡片贴到桌面，作为便签随时查看与调用。

### 内容复用

- 单击卡片重新复制；双击卡片可直接粘贴到之前使用的应用。
- 通过全局快捷键唤起面板与搜索，支持键盘选择和快捷操作。
- 保存和导出内容；导入已有资料，便于迁移和备份。

### 截图、OCR 与录屏

- 区域截图，支持矩形、圆、箭头、画笔、文字和马赛克标注。
- 使用 Apple Vision 在本地识别图片文字，将识别结果与图片记录关联。
- 区域录屏，支持 MP4 与 GIF 输出，并在历史中管理和复用。

## 典型使用场景

- **AI 对话与提示词管理**：保存常用 Prompt 和有价值的回答，添加标题并固定，后续按关键词找回。
- **开发与资料研究**：集中保留代码片段、文档链接与问题描述，减少跨窗口反复翻找。
- **日常办公**：复用地址、开票信息、固定回复和文案片段。
- **视觉素材整理**：保存参考截图，识别文字、补充标注，再次复制或导出。

## 技术架构

项目采用 macOS 原生桌面架构，使用 Swift Package Manager 管理构建，主要依赖 Apple 系统框架与系统 SQLite 库，无第三方包依赖。

核心数据流程：**系统剪贴板 / 截图与录屏 → 内容识别与去重 → 本地文件和 SQLite 索引 → 搜索与卡片面板 → 编辑、导出或再次粘贴。**

| 层级 | 技术与模块 | 职责 |
| --- | --- | --- |
| 应用与交互层 | Swift、AppKit、SwiftUI；`App/`、`Shelf/` | 菜单栏入口、全局快捷键、设置、卡片面板和桌面便签 |
| 内容采集层 | `NSPasteboard`、ScreenCaptureKit；`Clipboard/`、`Capture/` | 监听剪贴板变化，采集截图与录屏，识别内容类型 |
| 本地存储层 | SQLite、文件系统；`ClipDB`、`ClipStore` | SQLite 保存元数据和索引，文件系统保存文本与媒体正文 |
| 搜索与生命周期层 | Swift Concurrency、`ClipSearchIndex`、`Retention` | 在 actor 中执行正文读取与关键词匹配，通过缓存、查询取消和输入防抖保持界面响应；按保留期清理记录 |
| 图像与媒体处理层 | Vision、CoreGraphics、TextKit、AVFoundation、ImageIO | 本地 OCR、标注排版与渲染、视频写入和 GIF 编码 |

当前搜索采用归一化后的字面量关键词匹配，尚未实现向量检索或 AI 语义搜索。文本正文的搜索范围限制为前 200,000 个字符。

## 数据与权限

- 剪贴板记录与媒体文件保存在本机，没有账号系统或剪贴板云同步。
- 采集逻辑会跳过带隐藏、临时或自动生成标记的剪贴板内容，并识别常见密码管理器来源；暂停或锁屏期间不记录。
- 截图与录屏需要系统的屏幕录制权限；自动粘贴需要辅助功能权限，缺失时可退化为复制。
- 文件条目仅保存路径引用，原文件移动或删除后，引用可能失效。
- 当前代码保留上游的更新检查逻辑，会访问上游 GitHub Releases，可在设置中关闭。独立发布前需调整更新来源。

## 本地开发与当前状态

环境要求：macOS 15 或更新版本、Swift 6 工具链及可用的 Xcode Command Line Tools。构建脚本支持本机架构，也提供 Intel / Apple Silicon 通用构建路径。

在本项目目录执行：

```bash
./build.sh
```

**当前完成的是项目介绍更名。** 源码目录、模块名、应用标识、部分界面文案和构建产物仍沿用上游命名，因此现有脚本输出为 `build/Pastory.app`，数据目录仍为 `~/Library/Application Support/Pastory/`。本文使用 PasteTrail 作为本地二次开发项目名称，不表示应用内更名已完成，也不代表已有独立安装包或公证发布。

现有开发约定见 [开发文档](docs/DEVELOPMENT.md)。后续独立应用更名需同步检查存储位置、系统权限、应用标识与更新来源。

在现有历史保存和复用能力之上，计划探索对用户选中内容进行 AI 摘要、改写、待办提取及知识卡片整理，形成从采集到加工再到复用的工作流程。
